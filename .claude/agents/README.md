סוכנים ייעודיים לפרויקט LibraryOS, כל אחד כקובץ `<שם-סוכן>.md` עם frontmatter (`name`, `description`, ואופציונלית `tools`/`model`).

## הסוכנים הקיימים

- **`permission-check.md`** — סוכן ביקורת read-only שבודק שינוי ספציפי (לא את כל הריפו) מול 4 הכללים הבלתי-מתפשרים של הפרויקט: הרשאה בשתי שכבות (UI + נקודת המוטציה), RPC אטומי לתקציב/מלאי (לא רצף קריאות), אי-ערבוב בין תהליך רכש ספרים לתהליך ציוד/שירותים, ומשמעת מיגרציות (קובץ חדש, לא עריכה). מומלץ להריץ אחרי מימוש כל שינוי שנוגע לסטטוס הזמנה, סכומי תקציב/זיכוי, מלאי, או פעולה רגישה חדשה.

תיקייה זו נוצרה מראש לפי בקשת המשתמש (ראה `.claude/plans/replicated-moseying-reef.md` §0) — אפשר להוסיף כאן סוכנים נוספים בעתיד באותו פורמט.
